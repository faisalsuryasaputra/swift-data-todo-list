# 📝 SwiftData To-Do List

A modern iOS task management application built using **SwiftUI** and **SwiftData**. This project demonstrates the implementation of CRUD (Create, Read, Update, Delete) operations with persistent local storage.

## 📱 Key Features

* **Smart Input:** Task input form using a *Sheet* and *Graphical Date Picker* for a seamless user experience.
* **Due Date System:** Displays task deadlines. Dates automatically turn **Red** if the deadline has passed (Overdue).
* **Auto Sorting:** Tasks are intelligently sorted based on the nearest due date.
* **Interactive UI:**
    * Swipe-to-delete functionality.
    * **Haptic Feedback** (vibration) when completing tasks.
    * Snappy animations for checklist interactions.
* **Empty State:** A friendly and clean UI when there are no active tasks.

## 🛠 Tech Stack

* **Language:** Swift 5.9+
* **Framework:** SwiftUI
* **Database:** SwiftData (The modern replacement for CoreData)
* **Platform:** iOS 17.0+
* **Architecture:** MVVM (Model-View-ViewModel) concepts.

## 🚀 Getting Started

1.  Clone this repository:
    ```bash
    git clone [https://github.com/faisalsuryasaputra/swiftdata-todo-list.git](https://github.com/faisalsuryasaputra/swiftdata-todo-list.git)
    ```
2.  Open the `ToDoList.xcodeproj` file using **Xcode**.
3.  Ensure the Minimum Deployment Target is set to **iOS 17.0**.
4.  Press `Cmd + R` to run the app in the Simulator.
